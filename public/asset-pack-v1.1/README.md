# Cozy Home & Garden 2D Game Asset Pack v1.1

Expanded pack based on the user-provided hand-drawn home, nursery, bedroom, bathroom, studio, kitchen, garden, farm, pet-care, and gallery screenshots.

## Contents
- `assets/`: original 47 assets plus 83 newly catalogued additions.
- `reference/source_scenes/`: all supplied source screenshots used for this expansion.
- `catalog/`: original atlases plus expanded per-category atlases and full catalog preview.
- `manifest.json`: complete machine-readable asset list and metadata.
- `AGENT_HANDOFF.md`: integration guidance and quality warnings for the receiving agent.

## Quality convention
Transparent cutouts are best-effort extractions from flattened screenshots. Some assets remain composites. Opaque crops preserve source backgrounds and serve as reference fragments. Consult `quality`, `extraction`, `transparent_background`, and `notes` in the manifest before use.
